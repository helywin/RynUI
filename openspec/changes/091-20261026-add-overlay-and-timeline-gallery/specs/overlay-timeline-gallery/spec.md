# Spec Delta

## Purpose

为 RynUI 使用者提供可从组件目录直接进入的浮层编辑、消息通知及处理记录示例，使用真实原生输入和操作展示已实现组件的内容更新、布局切换与关闭恢复，保留既有 Gallery 的使用行为。

## ADDED Requirements

### Requirement: 浮层编辑与恢复

Gallery SHALL 提供可打开、编辑和保存的 Popover，支持切换位置、箭头及禁用状态，普通开合及配置更新保留输入草稿和控件身份。

#### Scenario: 编辑后关闭和重开
- **WHEN** 使用者从目录打开浮层，输入备注并保存，随后重开和切换配置
- **THEN** 反馈显示实际备注，受控开合正确，输入草稿及控件身份保持，禁用后可由外部操作恢复

### Requirement: 消息通知的键控流程

Gallery SHALL 使用窗口内真实 Message/Notification holder 提供打开、同 key 局部更新、关闭与清空；通知包含可编辑富内容，展示位置和状态变更。

#### Scenario: 通知内容保留
- **WHEN** 使用者打开通知、编辑内容，再更新同 key 的标题或状态并改变位置
- **THEN** 当前通知与输入身份保持、草稿不丢失，实际反馈与操作一致，关闭或清空移除该通知且外部入口仍可重新打开

### Requirement: 可编辑的处理记录

Gallery SHALL 提供竖向 Timeline，展示三种位置、正反序、loading、条目显隐以及可提交的备注；恢复控制不放在被隐藏条目中。

#### Scenario: 排序和显隐恢复
- **WHEN** 使用者编辑备注、改变位置与顺序、隐藏并恢复备注条目
- **THEN** 保存反馈显示真实备注，普通草稿与控件身份保留，隐藏时不可命中，恢复后可继续编辑

### Requirement: 目录与有限空间中的真实操作

四个目标组件目录 SHALL 直接定位对应真实示例，在 Default、Dark、Compact 和宽窄有限视口中均可使用指针及键盘完成主要操作，绘制与命中遵守实际分配区和窗口层边界。

#### Scenario: 从目录进入并操作
- **WHEN** 使用者点击目录后操作浮层、通知或处理记录
- **THEN** 对应示例可见，实际 glyph、fill、hit 和焦点装饰符合内容区域及外部裁剪，浮层不受错误的文档裁剪限制

### Requirement: 既有样例兼容

Gallery MUST 保留旧 stable IDs 的相对顺序、旧样例函数体及非目标支持信息；规划和支持状态不能替代运行证据。

#### Scenario: 新示例追加
- **WHEN** 新流程加入目录、盘点和完整 Gallery 入口
- **THEN** 旧流程保持原顺序，精度、内容所有权、reset 和输入保留断言不弱化，新增数量由实际盘点确认
