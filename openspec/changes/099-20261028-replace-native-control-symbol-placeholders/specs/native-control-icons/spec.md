# Spec Delta

## Purpose

让原生控件的导航、展开和排序操作统一使用内置图标资源，避免将文本字体中的相似字符作为控件图标；普通内容仍保持文本语义，并保留当前受控状态、事件和 retained 身份。

## ADDED Requirements

### Requirement: 控件操作使用正式图标

DatePicker 导航、Menu 子菜单展开、Pagination 翻页／跳转和 Table 排序 SHALL 使用 RynUI 内置图标资源。普通日期、页码和标题 SHALL 保持文本，不得依赖文本字体是否覆盖相似箭头字符来绘制操作图标。

#### Scenario: 日期与分页导航
- **WHEN** 用户查看日期前后月／年及分页前后页／跳转操作
- **THEN** 对应操作显示正式图标，数字与标签仍为文本，原点击、禁用和键盘语义保持

### Requirement: 状态更新保持图标和身份

图标方向和状态 SHALL 随原受控状态更新，不重挂载无关内容；主题色、字体尺寸及既有裁剪和输入资格 SHALL 保持适用。

#### Scenario: 菜单展开与表格排序
- **WHEN** 子菜单开合或表格排序从无排序切换为升序／降序
- **THEN** 实际图标随状态更新，图标与控件完整 generation 保持，原回调与受控拒绝行为不改变
