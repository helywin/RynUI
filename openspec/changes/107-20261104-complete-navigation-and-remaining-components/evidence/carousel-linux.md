# Carousel Linux 验收

- 平台：Linux / GCC / HEADLESS，`linux-gcc-headless`，Ninja Multi-Config，锁定 BUNDLED source 缓存；Debug 与 Release 独立构建，最大 `-j2`。
- 配置：`cmake --preset linux-gcc-headless`。构建命令为 `cmake --build --preset linux-gcc-headless-{debug,release} --target rynui_carousel_tests rynui_calendar_tests rynui_paint_opacity_tests rynui_carousel_gallery_tests rynui_calendar_gallery_tests rynui_theme_algorithm_tests rynui_theme_runtime_tests rynui_portable_theme_public_api rynui_portable_logical_scene_packing rynui_portable_button_scene_service rynui_portable_pointer_route rynui_portable_rounded_effect_scene -j2`；每个配置 12 个相关 target 构建通过。
- 最终 CTest：`ctest --test-dir out/build/linux-gcc-headless -C {Debug,Release} -R '^rynui.(carousel_|calendar_|paint_opacity$|theme_algorithm$|theme_runtime$|portable.(theme_public_api|logical_scene_packing|button_scene_service|pointer_route|rounded_effect_scene|backend_boundaries)$|gallery_sample_source_generated$)' --output-on-failure`；每个配置 **35/35 通过，0 失败**。包含 13 个 Carousel 合同、9 个 Calendar 合同、2 个独立 Gallery、共同 paint opacity、Theme/golden/源生成/公开 API/Core 边界。
- Carousel 覆盖：实际 native Button CPU 内部像素与 glyph 透明度、ScrollX/Fade 中途几何、adaptive height 中途高度、RTL/纵向/无限边界无克隆、受控拒绝/同步接受/dontAnimate/方向、稳定 key 重排与移除 fallback、局部 content 替换/工厂回滚/无效拓扑不重试、Ref stale/thread 检查、背景拖动/多指/cancel/reduced motion/capture、TextArea 草稿/Core preedit/嵌套 Popover 退休、零尺寸/隐藏/卸载、异常与回调重入清理。
- 自动播放覆盖：假单调时钟 deadline、手动 pause/play、hover/focus/隐藏/失活/reduced motion、剩余时间恢复、显式 dot progress 的半透明底色和实际增长段、手动切换重置、静止帧计数与销毁后无定时器。编辑器自己的光标 deadline 与 Carousel 暂停分开检查。
- 共同 Core 包络覆盖原生 Text/Icon/Input/Button、Quad 与 RoundedEffect、嵌套 opacity、零值恢复、可变 range remap、无静止帧循环及析构；保持 logical CPU scene v3 与既有 GPU ABI，未添加 renderer/SDL 依赖或私有上传。初期发现的受控接受回执、Theme 相等性与裁剪/焦点缺口均已修复；最终无遗留失败。
- Gallery：独立 Carousel 页面含普通保留面板及受控/自定义 dot 两组样例，真实箭头/dot、效果、自动播放/pause/play、拖动、草稿、动态列表与回调；CPU Gallery 测试实际点击箭头并检查 hover 绘制。与 Calendar 合计新增 4 个样例，生成器统计 **91 → 95**，原 **458** 个冻结 ID 保留。
- 五份完整 Theme golden 均为 **64** 个顶层字段，原 **62** 个字段（identity 除外）逐字段保护；独立 Calendar/Carousel 域参与相等性、hash、继承与定向失效，旧 TokenIdentity 名称与顺序不变。固定版本 Default/Compact 的 dot/arrow 尺寸、间距和颜色经过定向检查。ThemeConfig 新字段追加在原有字段之后，保留旧聚合初始化顺序。
- `clang-format 22.1.3` 检查 970 个自有源码，0 失败；catalog `--check --self-test`、source generator `--check`、OpenSpec doctor healthy、全部 strict validate **107/107**、`git diff --check` 通过。公开 Calendar/Carousel 例子均由实际合同 target 编译并挂载。
- 边界：以上为 HEADLESS/CPU 场景与输入服务证据；本工作 **GPU/原生窗口运行 0、Windows/MSVC 运行 0**，未做实际桌面、系统 IME 或 OS 辅助技术验收。63.3、64.3、65.1 保持父线程范围。图像解码/上传由并行 Image/Upload 工作负责；新增图像绘制在集成时应遵守共同祖先 paint opacity 合同。原始日志、源码副本与临时产物仅在忽略的 `out/calendar-carousel/`。
