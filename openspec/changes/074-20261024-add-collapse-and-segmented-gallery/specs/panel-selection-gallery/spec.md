# Spec Delta

## Purpose

为折叠面板与分段选择提供可实际操作、可观察状态回写并保留编辑内容的参考示例，使用户能够直接体验组合方式，同时保持已有目录和示例身份。

## ADDED Requirements

### Requirement: 可操作的折叠面板与分段选择

Gallery SHALL 展示 Collapse 的受控展开、accordion、禁用与独立 extra，以及 Segmented 的受控选择、横纵向/等宽、图标和禁用；状态反馈 SHALL 反映真实操作。

#### Scenario: 滚动后操作和编辑保留
- **WHEN** 用户滚动到样例、编辑面板正文、切换面板和分段选项
- **THEN** 展开/选择与反馈更新，关闭正文退出焦点和子浮层，重开仍保留已有编辑内容与身份，extra 操作不意外切换面板。

### Requirement: 目录与验收范围准确

Gallery SHALL 保留既有目录/示例与状态，记录两组件首版范围和独立平台边界，并通过共同场景验证实际交互。

#### Scenario: 主题和宽度变化
- **WHEN** 用户切换主题或窗口宽度并访问新样例
- **THEN** 内容保持可操作和身份稳定，目录注明实际支持范围，平台通用结果不被描述为未执行的原生平台验收。
