# Spec Delta

## Purpose

规定 Gallery 滚动同步的可观测工作量与局部优化的结果等价边界。

## ADDED Requirements

### Requirement: 滚动同步阶段应可复测
系统 SHALL 在真实窗口自动滚动验收中报告同步子阶段 CPU 时间和实际访问/更新规模，并区分完整帧、提交 CPU 与未测 GPU 执行。

#### Scenario: 固定滚动序列
- **WHEN** 同一正式 Release 窗口运行固定的自动滚动序列
- **THEN** 输出足以区分文本、参与者、effect、fragment、命中与场景拼装工作的计时及工作量，并记录实际后端和完成状态

### Requirement: 滚动局部化不得改变结果
系统 MUST 在减少无关同步工作时保留文本像素 phase、布局与裁剪、primitive 顺序、交互命中及重新进入视口后的最新状态。

#### Scenario: 文字离开并重新进入视口
- **WHEN** 文本在滚动中离开可视区域后内容或视觉属性发生变化，再滚动进入视口
- **THEN** 首个可见帧显示最新内容且无旧 glyph 或错误位置

#### Scenario: 分数滚动与裁剪变化
- **WHEN** 滚动偏移含分数像素或视口 clip 变化
- **THEN** 文本位置、像素对齐、裁剪与完整同步参考路径一致

#### Scenario: 无关节点变化
- **WHEN** 滚动期间仅部分内容的视觉结果需要更新
- **THEN** 系统可跳过经证明无影响的昂贵同步工作，并以访问/更新计数证明跳过范围
