# Spec Delta

## Purpose

为使用者提供能从组件目录直接进入的联系人建议与项目树流程，通过真实原生输入、选择、勾选及保留备注展示两个已发布组件的可用范围。有限空间内的反馈、焦点与草稿和实际操作一致，并明确区分定向验证和平台验收。

## ADDED Requirements

### Requirement: 联系人建议与受控反馈

Gallery SHALL 提供可自由输入、过滤及更新建议、键盘选择和清空的联系人流程；拒绝受控修改时反馈与实际接受值一致，禁用和只读可恢复。

#### Scenario: 输入并选择联系人
- **WHEN** 使用者从目录进入联系人样例，输入查询并通过指针或键盘选择建议、切换接受策略或编辑门禁
- **THEN** 建议和实际接受值正确，禁止编辑时不能修改业务值，恢复操作位于禁止输入的区域之外

### Requirement: 建议富内容与表单重置

Gallery SHALL 提供保留备注的富建议及可重置的表单字段；普通建议更新保留草稿，表单同值 reset 清除未提交的候选/草稿与组合输入。

#### Scenario: 更新建议并重置字段
- **WHEN** 使用者编辑富建议备注、更新建议，再保持字段焦点执行 reset
- **THEN** 普通更新不重建备注控件，reset 恢复接受值且不会在随后确认时复活旧草稿，反馈和焦点行为与实际操作一致

### Requirement: 项目树操作与保留备注

Gallery SHALL 提供固定项目层级的展开、单选、级联勾选、禁用隔离及有限滚动；富标题的真实备注控件在普通状态更新中保留，隐藏和禁用可恢复。

#### Scenario: 勾选项目并恢复编辑
- **WHEN** 使用者通过指针或键盘展开、选择和勾选项目，编辑备注后隐藏或禁用树再恢复
- **THEN** 反馈反映实际展开/选中/全选或半选状态，禁用分支不被级联修改，备注与控件身份保持且旧临时输入状态已清理

### Requirement: 真实目录与有限区域可操作性

两个组件目录 SHALL 直接进入对应实际样例；三主题和宽窄有限视口中，文字、填充、命中与适用控件的焦点装饰遵守文档和窗口层边界。

#### Scenario: 从目录完成主要业务操作
- **WHEN** 使用者点击两个组件的目录入口并操作输入或树节点
- **THEN** 样例实际可见，必要滚动能到达目标，真实绘制/命中及适用焦点轮廓有效，普通配置更新保留控件完整代际

### Requirement: 既有流程与准确支持范围

Gallery MUST 保留旧 stable IDs 相对顺序、旧样例函数与调用顺序、非目标组件支持状态及已经发布的组件和资源行为；新增数量与支持信息以实际实现和验收为准。

#### Scenario: 追加联系人和项目树
- **WHEN** 新流程接入默认完整入口和定向验收
- **THEN** 旧流程保持兼容，两条目标条目如实记录首版范围，定向 Recording 不冒充完整 Gallery、GPU、Linux、系统 IME 或辅助技术通过
