# Spec Delta

## Purpose

在内容规模增长后，保持纯滚动时的文字、导航和输入行为，并以可重复的原生测量揭示实际成本。隐藏文字不应持续占用可见场景上传，重新进入视口时必须恢复正确内容，测量应明确区分启动和滚动阶段。

## ADDED Requirements

### Requirement: 不可见输入文字恢复

系统 SHALL 避免向可见场景发布完全裁剪或透明的输入文字层，并在重新可见时恢复最新文字、选择和样式，保留 editor、ref 与输入状态。

#### Scenario: 屏幕外更新后重新显示
- **WHEN** Input 被完全裁剪，更新内容后再滚动回视口
- **THEN** 实际 glyph 和 clip 恢复为新内容，editor 与组件完整代际不变

### Requirement: 滚动导航一致

Gallery SHALL 在纯位移中复用有效目录定位信息，在布局变化后更新定位；目录点击仍到达最新样例位置。

#### Scenario: 重排后导航
- **WHEN** 窗口宽度或内容布局变化后点击目录
- **THEN** 跳转使用重排后的目标位置，普通滚动不重复遍历全部文字求锚点

### Requirement: 原生滚动测量边界

滚动验收 SHALL 只统计采样区间的同步与上传，报告实际配置、视口、平均和 p95，并继续拒绝区间中的额外 reconciliation。

#### Scenario: 启动后滚动
- **WHEN** 初始布局完成并开始自动滚动采样
- **THEN** 启动计数被排除，采样区间中的额外同步仍计入失败条件
