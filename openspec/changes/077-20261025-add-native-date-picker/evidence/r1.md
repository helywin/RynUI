- `review_inheritance`：`R1: disabled component algorithm discarded inherited tokens`。父级 selected override 因子级未启用算法却带有 local seed 而丢失。

## 修复

DatePicker 的日历边界 fallback 独立于内容 scroll handler，在全部 participant 内容处理后才执行，沿实际最近 window layer 归属判断；不改变 host 注册/键盘优先级。逐项验证 override 后的最终派生度量，包括未提供 override 的 fallback。未启用 DatePicker algorithm 时，local seed 不参与继承决策；显式启用仍独立派生。
