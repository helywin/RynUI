```text

ctest --preset windows-msvc-headless-debug -R "^rynui.date_picker_review_" --output-on-failure
```

修复前 **0/3 通过，3/3 失败**，失败原因分别为：

- `review_wheel`：`R1: DatePicker boundary swallowed footer Table wheel`。显式打开祖先 Table 内 DatePicker，稳定有限布局后，footer Table body 实际为 264×96，maximum_x=156、maximum_y=1210；真实 wheel dispatch 返回 consumed，但 Table.scroll_y 不变。
- `review_metrics`：`R1: negative derived DatePicker metrics published`。`Compact + date_picker.algorithm=true + seed.control_height=dp(1)` 未在 snapshot 发布前拒绝。
- `review_inheritance`：`R1: disabled component algorithm discarded inherited tokens`。父级 selected override 因子级未启用算法却带有 local seed 而丢失。

## 修复

DatePicker 的日历边界 fallback 独立于内容 scroll handler，在全部 participant 内容处理后才执行，沿实际最近 window layer 归属判断；不改变 host 注册/键盘优先级。逐项验证 override 后的最终派生度量，包括未提供 override 的 fallback。未启用 DatePicker algorithm 时，local seed 不参与继承决策；显式启用仍独立派生。
