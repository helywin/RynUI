- Windows 39 项定向 Python 测试通过。校准报告定位到控制标识、逻辑矩形及已观察的峰值。字形、图标和阴影的硬门槛保留首次失败侧别及物理坐标。开启诊断前后判定相同，留出与故障安全间隔检查仍生效。
