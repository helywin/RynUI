# 控制板证据路径与低对比度像素

- 独立字形与 SVG 见证工具按仓库相对路径解析。控制流、截图与启动回执按证据目录解析。采集完整性清单在计算 verdict 前保存，以便保留失败运行的完整出处。
- 极低对比度的纯色矩形以声明几何的单位像素面积独立求证。固定 Chromium 核对软件混合后的精确 RGB8 字节，原生核对 GPU 归一化取整。黑白控制继续按原上限验证覆盖、轮廓和邻近区域。边缘丢失、内区误色和 guard 泄漏仍有独立判据。
- Windows hidden D3D12 在 DPR 1.5、Linux 私有 Wayland/Vulkan 在 DPR 1 的训练与留出控制，各重测 312 个样本，四组均在原有硬上限内。源路径、取整负例和校准收据由定向 Python 测试覆盖。
- Linux 的正式运行已采集重复、重启和全部负控制。第一轮在见证工具路径解析处返回错误。修复后的完整证据重算和 profile 发布仍待核验。
