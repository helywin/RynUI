# SVG 图标光栅边缘

固定 Skia 在紧贴临时位图原点绘制 SVG 时，会改变清除图标最右列的两个边缘样本。临时 A8 位图增加四个物理像素的留边，保留原字形尺寸、相位和图集采样坐标。

Windows MSVC 原生 Release 的 `rynui.default_font_chain` 通过（1/1）。D3D12 实际截图中的 18×18 清除图标在 Input 三个检查点都与固定 Chromium 像素逐点一致，各由 322/324 提高到 324/324。用原判定阈值重放，Input 初始检查点无差异，三检查点合计由 42 条降至 36 条。警告态的叠加边缘仍有差异，整例验收保持开放。
