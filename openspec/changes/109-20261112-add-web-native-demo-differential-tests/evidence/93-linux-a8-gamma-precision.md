# Linux 灰度字形的 Gamma 精度

Fontations 灰度掩码使用 Skia 实际记录的 2.6 定点 Gamma 值 76/64。普通和合成字形片元程序按相同精度求灰度传递，独立见证采用同一规范。DirectWrite 路径维持原值。

修复前，真实 Linux 校准的留出组文字轮廓距离约为 0.498 像素，高于训练上限 0.385 像素。修复后，在私有 Wayland/Vulkan 上重画两张独立控制板，训练与留出组的字形覆盖质量、轮廓与投影误差均为零。此重画没有发布轮换校准档案。Linux 着色器合同和合成布局 2/2、分层数学测试 35/35 通过。Windows 与 Linux 的普通字形和合成字形着色器均完成编译和反射。
