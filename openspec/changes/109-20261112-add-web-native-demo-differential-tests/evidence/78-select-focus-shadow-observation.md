# 下拉阴影与焦点边重叠的判定

- 保留每个来源的实际颜色、透明度和绘制顺序。颜色轴在 RGB8 上无法稳定拆分时，限定的硬聚焦边和相邻阴影使用由来源端点计算的 RGB 包络，按同一个参考输出坐标比较。每层半个码值的舍入上界仍须通过既有重叠上限。
- 71/71 定向 Python 检查，包含漏掉焦点覆盖、错误通道、低对比不可辨识和多条软阴影的边界。
- Windows D3D12 1.5× Select 打开态复用实采截图，三段文档和一个弹层裁区全部返回判定。原来先报校准中止的位置现在能报告实际视觉差异。原生两处焦点边取到 RGB 145/202/255，固定 Web 参考实际为 230/244/255。该场景的正式 paired 判定仍未通过。
