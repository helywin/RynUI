# 双平台基线校准和运行内复核

在 `fce6d33d` 的正式 Release 构建上，Linux 私有 Wayland/Vulkan 实际 DPR 1 与 Windows 隐藏 D3D12 实际 DPR 1.5 分别通过独立校准并发布 profile。每个平台对训练集与留出集各执行五次重复和一次独立重启，26 组负例均通过预期检出检查。16 项指标遵守原有硬上限。两个 profile 各自绑定当时的二进制、环境和比较器。

每次 `run`、`replay` 或 `meta-test` 仍在采集前完整重算校准证据。同一次调用内的各案例复用这份已经复核的内存副本，逐案检查 profile、二进制、解码器和实际配对环境的身份。相关单元测试覆盖重复复核计数和输入身份变化。基线校准结果与整套 pilot 配对判定分别记录。

旧版 Linux 配对发现像素差异后，报告曾因 Python 坐标元组无法满足严格 JSON 协议而写出失败。坐标、来源列表和 ROI 现在按 JSON 数组发布，回归用例同时断言实际差异和报告数据类型。旧短检查点仍可复放，提供分块的检查点必须包含样例锚点及真实回读绑定。
