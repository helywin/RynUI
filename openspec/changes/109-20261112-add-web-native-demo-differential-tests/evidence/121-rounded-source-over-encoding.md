# 硬阴影与圆角边框的 RGB8 合成

独立控制程序分别重建 Chromium 的有色光栅合成和 SDL 的逐层 RGB8 合成。两侧实际发布的圆角、阴影、图层顺序和材质须先配对，且两个读回像素都须逐通道等于各自的预测。额外绘制层、裁剪、透明度组或不符的像素继续走原判定。

Windows MSVC 原生 Release 控制程序精确复现了代表点的 Chromium `(254,236,191)` 与 D3D12 `(254,237,192)`。无效原点返回 4，未生成回执。65 项形状、分层和区域测试通过，含单侧错色、同色和移动几何负例。

用原阈值重放 Windows D3D12 与固定 Chromium 的实际截图，Input 三个检查点由 0/18/18 变为 0/0/0。Button 四个检查点保持 45/46/47/51。正式三例 pilot 和 Linux 仍待本版本复验。
