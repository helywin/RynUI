# 圆角边框的部分覆盖

锁定 Skia 的圆角描边与双圆角边框分别从自己的源几何生成 R8 样本。只有几何、物理位置、材质和覆盖字节一致时才使用该字节修正纯色预测。可变覆盖率像素、色差阈值和轮廓检查继续按原合同处理。

MSVC 原生 Release 控制程序复现两条路径在物理坐标 (1, 240) 的覆盖字节 248。非法坐标返回 4，未生成回执。62 项 Python 形状、分层和区域测试通过。使用相同的 Windows D3D12 与 Chromium 截图重放，Input 三个检查点各消除三条纯色误报，总差异从 51 降到 42。Button 的四个检查点结果一致。整例像素验收仍开放。
