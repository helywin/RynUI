# 禁用 Select 官方 SVG 的视口与 RGB8 合成

- Windows MSVC Release 隐藏 D3D12 与锁定 Chromium 在 1.5× 的真实 Select 初始裁剪中，官方 DownOutlined SVG 的视口与原生图标的画布一致。依据锁定路径和栅格遮罩，10 个全覆盖像素分别等于 Chromium 的 183 和 D3D12 的 184，使用错误的通道代码会被拒绝。
- 使用原始读回重放三个初始裁剪，报告中的高对比字形色差由 16 项降到 6 项，其他报告类别计数一致。分层测试 51/51。原采集、阈值与基于未覆盖像素的判定保持一致。
- 此次验证覆盖指定图标的确定性全覆盖差异。完整套件仍待复验。
