# Select 长样例分块和弹层边界

Linux GCC Release 隔离构建使用私有 Wayland/Vulkan 和锁定 Chromium，在真实 100% 缩放下完成 Select 十个检查点。两侧每个检查点各有三张独立分块图。1792 logical px 的样例全高、两条拼接边和保护区均有实际回读覆盖。逐个移除分块时，覆盖断言均失败。

窗口层弹层及完整阴影使用原检查点的独立回读，文档分块使用各自的实际裁剪。选项、自定义内容和异步弹层都有独立边界。浏览器采集画布为阴影留出了空间。采集侧需要最长 180 秒，Web 及原生侧都消费同一个显式超时，旧页面和校准入口沿用原有预算。

只允许经实际计算样式确认隐藏或完全透明的节点缺少浏览器绘制次序。单边下划线只按可见边和斜接区域计入，文字墨迹允许伸出布局 advance 框。以上验证覆盖采集完整性与定向绘制来源，Select 的整体像素差分继续验收。
