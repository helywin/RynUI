# 正式 SVG 控制的分数绘制位置

- 独立图标控制从实际 DOM 核对 SVG 根和外层校准节点。只接受固定输入声明的外层平移。实际路径、矩阵、缩放、裁剪、顺序和正式资源仍独立检查，普通样例继续拒绝未声明变换。40 项定向 Python 测试通过。
- Windows D3D12/DXIL，DPR 1.5 的实际 40 个留出图标，最大轮廓距离从 1.770 降至 0.948 physical px，局部覆盖误差从 0.7590 降至 0.4938。Linux 私有 Wayland llvmpipe Vulkan/SPIR-V 实际 DPR 1 亦验证 40 个图标的来源，轮廓距离和支持范围仍有超限。
- Windows 实际两侧都绘制错误图标的控制仍在 `p1.icon0` 的正式资源检查失败。两平台均未发布校准 profile。
