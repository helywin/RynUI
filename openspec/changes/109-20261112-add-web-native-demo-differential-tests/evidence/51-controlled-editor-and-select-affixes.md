# 受控编辑与 Select 富前缀

- 受控 Input 在回调后读取最新值。同步拒收立即反映到编辑器绘制，批处理中的同步接收保留光标和编辑历史。Select 富前缀参与高度测量并跟随 RTL，显式最大高度继续生效。
- Web 快照分别观察样例内实际挂载的编辑器，并保留每个编辑器的字形证据。原生视觉快照跳过未激活分支。Button 样例的双汉字标签和显式 Loading 图标对应固定参考的内容与槽位。
- Windows MSVC HEADLESS Debug 和 Release 的组件与输入定向测试各通过 7 项。Windows hidden D3D12 和固定 Chromium 三个样例的 17 个真实检查点均通过独立语义断言。Button 和 Input 的已登记目标均达到 0.25 逻辑像素的相对布局上限，Select 两种弹层仍有位置或高度差异。配对像素判定仍待完成。
