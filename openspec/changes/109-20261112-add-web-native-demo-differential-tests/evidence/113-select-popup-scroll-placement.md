# Select 弹层随滚动保留锚点

打开时按选择器上下可用空间确定放置方向。文档滚动时，已选方向仍能容纳弹层就继续使用。触发器滚出视口时，弹层随锚点移动，由窗口裁剪隐藏。当前方向空间不足或显式修改 placement 时重新定位。

Linux GCC Release 的 `rynui.select_component` 通过，并在私有 Wayland、Vulkan、1× 下完成 Select 的 10 个主检查点和 30 张上下文图。四个虚拟与异步弹层检查点的主帧定位保持一致。修复前 12 个滚动分片共记录 36 层位置偏离锚点的阴影。修复后仍可见的 12 层阴影保持主帧相对位置，其余 24 层随弹层移出视口。锁定 Chromium 的观察基线在对应滚动时维持相同的锚点相对位置。整例像素验收仍开放。
