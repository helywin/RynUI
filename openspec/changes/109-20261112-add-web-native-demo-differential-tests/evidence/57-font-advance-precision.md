# 平台灰度字体的字宽精度

可缩放的平台灰度字体先按高精度 OpenType 字宽进行排版，再确定物理像素相位。锁定 Noto Sans 的字母 I 在 14 logical px 下宽 4.746。旧路径先取整到 4.75，在 150% 下使相邻字形跨过四分之一物理像素的边界。组件字重、字号及字体文件仍由原有输入决定。

用 Windows MSVC Release 的目标参数隔离编译并通过 FontRuntime 回归。真实隐藏 D3D12 的 Input 三个检查点保留 DirectWrite 的旧灰度像素生成方式。对照锁定 Chromium，两个采样文本带中相差至少 8 个灰度级的像素从 89 和 172 个降至 0。结论覆盖这两个文本带，整例配对仍由正式 runner 判定。
