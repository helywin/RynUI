# Input 硬阴影与描边角区

同一 Chromium paint node 的硬阴影与纯白填充、不透明描边组合，用原始 RGB8 坐标核对 source-over 端点域。两次编码各提供半个码值的量化界限，且只适用于同源、不带半透明 group 的组合。平坦色、轮廓、局部覆盖和层贡献的阈值保持锁定。

实际 1.5× Windows Input 两个聚焦检查点的固定 Chromium/D3D12 回放中，每次有两个像素被旧的单次量化约束误判。修正后这四个像素通过独立域检查。定向负例保留错色、异源、半透明 group 和有 blur 的组合拒绝。本次局部回放仍有光标和字形观测差异，未记为 pilot 通过。
