# Select 文字在半透明底色上的 RGB8 合成

Windows，D3D12 与锁定 Chromium 141.0.7390.37，DPR 1.5。Select 已选标签「桌面」的 1222 个像素在原始截图坐标下逐点比较，两侧高对比墨迹的位置一致，1023 个像素相同，其余 199 个像素各差一个色阶。

对于两端相同 glyph 和物理锚点、两个独立字体 mask 均为满覆盖的像素，分别计算透明黑底色及黑字对不透明白底的连续两次写入。锁定 Skia 的 `SkPMSrcOver` 整数路径给出 RGB 30，原生逐次 UNORM8 编码给出 RGB 29。仅在实际回读分别精确匹配该对字节时采纳此证据。

- `python -B tests/demo_differential_layered_tests.py` 49/49 通过，包含错色、缺字、错字、位移和底色变化负例。
- 用同一官方 Web 图和原生图重放 Select 初始检查点，报告中的高对比字形内色差从 72 项降至 16 项。总失败数仍触及逐区域报告上限，剩余字形支持域及覆盖待查，未更改阈值。

原始证据在本地 `out/nov19-differential/`。这项验证不覆盖整套三例或故障注入。
