# 字形光栅四分之一像素中点

字形横向光栅位置在精确中点采用最近偶数四分之一像素，正负坐标一致。整像素定位和非中点仍沿用原来的取整行为。

使用 Windows MSVC Release preset 的编译和链接规则单独重建 GlyphScene、Gallery 和 `rynui_glyph_scene_tests`。字形场景测试通过，覆盖正负中点、相邻非中点，以及 1×、1.25×、1.5×、2× 的尺寸和像素采样。隐藏 D3D12 窗口以 1.5× 重放受控 Input 的三个检查点。提交及拒绝画面中，`accepted` 末尾字形的两个溢出像素恢复为与固定 Chromium 一致的背景色，该字形的投影误差也已消除。其余文字和阴影差分另行验收。
