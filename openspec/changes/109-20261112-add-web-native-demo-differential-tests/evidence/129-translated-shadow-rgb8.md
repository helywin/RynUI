# 平移硬阴影与不透明圆角填充的 RGB8 复算

- Windows MSVC `windows-msvc-release`，校准工具构建通过。DPR 1.5 的 Button 原始两侧回读在两处边缘分别是 `(79,153,255)` / `(80,154,255)` 和 `(164,204,255)` / `(165,205,255)`。按共同尺寸、阴影位移、源颜色及固定绘制顺序独立复算，四组三通道字节分别精确匹配。
- 同一批原始 Button 回读在相同固定 hard cap 下重放。初始、悬停、Tab 检查点分别由 5/6/7 个诊断失败降为 1/2/5。几何或 alpha 变化、原始颜色偏离精确复算仍无法通过该分支。校准与形状见证的 Python 测试 32 项通过。
- 这是定向重放结果。仍保留阴影投影、焦点轮廓和其他覆盖差异，未获得完整平台 paired 或 meta 通过。
