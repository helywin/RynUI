# 多层不透明填充的 RGB8 来源

固定颜色比较对多层不透明填充使用与单填充一致的 RGB8 源色表示。只有候选字节色与提交色的 float32 位完全一致时，才使用候选值。实际像素、绘制顺序和校准上限继续参与比较。

Linux Vulkan / Chromium 141 的 Select virtual-mounted 曾在 `(11.5, 1460.5)` 结束。三个实际图层是白、RGB245、白，RGB245 的 float32 展开让原始误差估计略超过 .05。新重放完整处理该检查点的四个区域，继续报告几何、颜色贡献和软阴影差异。

分层测试 40/40 通过。RGB245 保持 .05 上限并能拒绝错色，RGB246 在同一源色条件下继续拒绝。
