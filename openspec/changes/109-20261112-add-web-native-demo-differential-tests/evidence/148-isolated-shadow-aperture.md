# Button 加载态阴影的合成范围

- 校验 Chromium 合成层的实际绘制范围，并对硬阴影分别计算 Chromium 和原生的 RGB8 合成。只在两侧底板均无覆盖、实际绘制顺序和裁剪一致、两个回读像素各自精确匹配时，使用同一阴影贡献。动画中的底板颜色继续单独比较。
- Windows MSVC `windows-msvc-release` 构建校准工具。用隐藏 D3D12 回读与锁定 Chromium 回读复验 Button 四个检查点，所测加载态阴影的投影相对误差降为 0。改动阴影处一个原生 RGB 像素后，误差为 0.328244，超过原有阈值 0.043105。共运行 69 项定向 Python 测试，全部通过。
- Linux Vulkan 归档回读用同一 Windows 校准工具复核初始阴影视窗，投影相对误差由 0.150943 降至 0.075472，仍有差异。此轮仅复验上述阴影路径，Button 其余差异、正式 pilot 与 meta 仍待验证。
