# 半覆盖轮廓的物理距离

- Windows 43 项定向 Python 测试通过，包含近似等覆盖的半覆盖交界、真正一像素位移、局部缺失、完整图层和校准证据。
- Windows D3D12 与固定 Chromium 的实际回读以半覆盖位置复算。DPR 1.5 训练板黑底七个形状控制的最大轮廓距离为 0.412 physical px。独立留出板在半 logical px 相位的最大值为 1.313，仍超过 0.5 上限。真实注入的单个边框向右移动 1 logical px 测得 1.863 physical px，保持失败。
- 形状和文字上限保留原值。覆盖积分、颜色、缺失墨迹和外溢仍各自判定。未发布校准 profile。
