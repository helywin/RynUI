# Select 多选标签继承触发器字体

内置标签的文字跟随实际 Select 编辑器字体，标签的行高和前景色仍来自 Tag，富内容自定义标签沿用自身样式。输入宿主销毁内部编辑器后，输入边界通知跳过对应 Select，避免重新布局已销毁的标签树。

MSVC HEADLESS Release 的 Select 组件、原生输入和原生观察测试 3/3 通过。定向回归确认普通和大尺寸分别使用 14 px 和 16 px，并保留标签的文字场景身份。Windows 1.5× 隐藏 D3D12 的十个检查点与锁定 Chromium 配对后，已通过文字字号、字重和 UTF-8 分组 advance 核对。整例像素验收仍开放。
