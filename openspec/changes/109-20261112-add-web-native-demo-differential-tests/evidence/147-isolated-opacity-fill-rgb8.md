# 独立 Chromium 合成面的不透明底板

- 锁定 Chromium 141.0.7390.37。Windows 1.5× 与 Linux 1× 各 105 个独立底色/透明度样本复现相同的 RGB8 编码。两平台真实官方 Button 的四个检查点均观测到同一透明度组内独立提交的动画子层。
- 使用对应的 Windows D3D12 和 Linux Wayland/Vulkan llvmpipe 原始读回及已锁定阈值重放加载态内部裁剪。Linux 原有 32 项独立色差和 32 项配对色差均消除。两平台各替换一个原生像素为 Web 的颜色时，均产生一项精确编码失败。
- 分层测试 52/52、形状见证 16/16。此次验证限定真实合成组中全覆盖的不透明填充。部分覆盖的阴影和文字仍按现有判定复验。
