# Input 清除图标与受控键盘焦点

Input 清除动作使用随 Theme 更新的小字号图标与默认、悬停、按下颜色，沿用实际后缀布局的行端位置。父级同步拒绝空值时保留已聚焦的清除动作。相同动作重试由父级接受后，编辑器呈现空值并退役不可见清除动作的命中资格。

Windows MSVC Release 的 Input clear component 回归通过，覆盖点击、键盘拒绝和接受、反应式可用性、输入法预编辑取消及回调内卸载。固定 Chromium 对照与隐藏 D3D12 窗口实际 1.5× DPR 复拍三个检查点。每个检查点的 33×27 物理像素清除图标区域，最大灰度差从 166 降到 1，差值至少 8 的像素从 464 降到 0。这里只记录清除图标和交互回归。
