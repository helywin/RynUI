# 硬阴影的 R8 覆盖率

固定像素渲染将有位移、零模糊和零扩张的圆角半透明阴影的材质 alpha 一次计入 R8 覆盖率，再由原绘制命令应用颜色。真实祖先 clip 继续作用于上传掩码。无位移的圆角填充沿用原路径。

MSVC Release / 隐藏 D3D12 与 GCC Release / 私有 Wayland Vulkan 的 composition shader 合同和实际回读分别通过 2/2。低 alpha 圆角新增精确边缘、实心和外部像素断言。两平台均重新采集 Button 的 4 个检查点。
