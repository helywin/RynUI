# 独立训练板的亚像素采样

- 原训练板的整数几何低估了部分覆盖、轮廓和阴影误差。训练板新增不同相位的裁剪、轮廓、合成与阴影样本，并使用与留出集不同的字形。训练集增至 384，留出集保持 312，指标硬上限、加量与负例间隔保持原值。
- Windows hidden D3D12（DPR 1.5）和 Linux 私有 Wayland/Vulkan（DPR 1）各实际测量 384 个训练样本，均在原有硬上限内。使用已采集的留出数据复算，两平台各 16 个指标满足训练与留出关系。Linux 与先前 26 个实际负控制复算时满足声明间隔。
- 以上复算使用单次新增训练采集和已采集的留出、负控制。新版完整重复、独立重启和负例重采集仍待执行，尚无新版校准 profile。
