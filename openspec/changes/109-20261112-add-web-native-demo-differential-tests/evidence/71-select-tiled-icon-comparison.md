# Select 分片图标与背景核对

- Windows 后台 D3D12 与固定 Chromium 的初始分片回放确认，Web 与原生的图标登记顺序不同。比较改为独立验证官方 SVG 和原生已提交字形，再核对当前有效分片的可见身份及数量。
- 真实回放检出原生前两片多出的 5 个、1 个静态清除图标。控件显示行为和第三片浅色覆盖计算仍需修复。
- 同一回放的前两片共 2,053,350 像素，空白批处理与逐像素实现的完整结果哈希一致。回归同时检查两侧出现同一个红色杂点时仍产生两条独立的原始颜色错误。
- Python 官方图标、分层比较、区域、颜色贡献、runner、协议与校准共 104/104 通过。
