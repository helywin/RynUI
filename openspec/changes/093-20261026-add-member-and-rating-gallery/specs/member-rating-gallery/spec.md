# Spec Delta

## Purpose

为使用者提供从组件目录直接进入的成员头像、统计指标和评分流程，使用真实原生控件展示数据更新、溢出访问及编辑恢复，在有限空间中保留可操作性与业务草稿，并准确区分已验收范围。

## ADDED Requirements

### Requirement: 成员展示与溢出访问

Gallery SHALL 提供文字及图标头像、形状/尺寸和成员组数量限制的真实操作；有限窗口中的溢出成员可访问，显隐恢复不丢失原有业务输入。

#### Scenario: 成员较多时访问溢出
- **WHEN** 使用者改变头像文字、形状、尺寸或成员组限制，并打开溢出成员
- **THEN** 实际头像与操作一致，所有隐藏成员可达，关闭及恢复后输入草稿和既有控件身份保持

### Requirement: 统计值与保留编辑

Gallery SHALL 使用真实 typed 数值及字符串展示精度、分隔符和格式化切换；loading 暂停对应富内容编辑，恢复后保留草稿。

#### Scenario: 更新格式和加载状态
- **WHEN** 使用者切换精度或格式化并启停 loading
- **THEN** 实际显示符合所选格式，反馈与实际值一致，加载门禁和草稿恢复有效，普通配置更新不重新创建富内容控件

### Requirement: 实际评分与编辑门禁

Gallery SHALL 提供受控评分、半星、清空和原生键盘操作，展示 disabled/readOnly 恢复和富提示中的真实输入；反馈来源于实际被接受的值。

#### Scenario: 评分并恢复编辑
- **WHEN** 使用者通过指针或键盘提交评分，切换编辑门禁并恢复
- **THEN** 实际半星和反馈与已接受评分一致，禁止编辑时不能修改评分，清空和恢复可用，富提示草稿与身份保持

### Requirement: 真实目录和有限空间操作

三个目标组件目录 SHALL 直接进入对应实际样例；Default、Dark、Compact 与宽窄有限视口中，绘制、命中和可交互控件的焦点轮廓遵守其分配区域及窗口层边界。

#### Scenario: 从目录进入并完成主要操作
- **WHEN** 使用者点击组件目录并操作成员、统计值或评分
- **THEN** 实际样例可见，主要操作可由真实指针/键盘完成，文字及填充不越界，可交互控件的外扩焦点装饰可见，浮层不误用文档裁剪

### Requirement: 保留已有样例与准确支持状态

Gallery MUST 保留旧 stable IDs 相对顺序、旧样例函数体与调用顺序及非目标组件支持信息；支持条目明确实现范围与未验收项目。

#### Scenario: 追加新业务流程
- **WHEN** 新流程接入默认完整入口及定向验收
- **THEN** 既有流程兼容，新增数量由实测确认，三条目标支持信息与实际实现一致，规划和定向 Recording 不代替完整 Gallery 或平台验收
