# Spec Delta

## Purpose

为 RynUI Gallery 提供可直接操作的原生空状态和结果页，展示它们与真实编辑控件、按钮和主题的组合关系。使用者能够观察描述、状态和图示变化，同时保留草稿与交互身份，并清楚了解首版支持范围。

## ADDED Requirements

### Requirement: 可操作的空状态与结果页

Gallery SHALL 提供默认、紧凑、自定义图示 Empty 与语义状态、异常、详情、操作 Result 样例，并使用真实原生按钮驱动响应式变化。

#### Scenario: 空状态操作与结果状态切换
- **WHEN** 使用者操作空状态按钮或切换结果状态
- **THEN** 相应描述或状态实际更新，目录能够定位这些样例，其他已有样例保持可用

### Requirement: 保留编辑内容

Gallery SHALL 在结果内容或操作 slot 中提供可编辑草稿，并在修改描述、图示、状态和 Theme 后保留相同编辑控件及其内容。

#### Scenario: 草稿跨展示更新保留
- **WHEN** 使用者编辑草稿，再切换结果状态、图示和默认/Dark/Compact Theme
- **THEN** 草稿值和控件身份保留，已有按钮继续可操作，不重复挂载内容

### Requirement: 有限视口与如实展示范围

Gallery SHALL 在宽窄视口正确约束实际图示和 glyph，稳定标识对应实际样例；目录与文档 SHALL 区分已实现原生语义、未覆盖插画和未执行平台验收。

#### Scenario: 窄视口与主题切换
- **WHEN** 在宽、窄视口切换三个主题并查看空状态与结果页
- **THEN** 实际可见图示与文本在分配区域内，所有新标识存在，目录不声称上游插画像素一致或未执行平台验收通过
